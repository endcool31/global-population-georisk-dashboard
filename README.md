# \# Global Population \& Geopolitical Risk Dashboard

# 

# A data-driven analytical dashboard assessing UN population projections and Iran geopolitical risk dynamics. Built for FinTech \& AI Applications.

# 

# \## 🔗 Project Links

# \- \*\*Live Demo (GitHub Pages):\*\* https://endcool31.github.io/global-population-georisk-dashboard/

# \- \*\*Repository:\*\* https://github.com/endcool31/global-population-georisk-dashboard

# 

# \## 📊 Pipeline \& Methodology

# 1\. \*\*Data Source:\*\* UN World Population Prospects (2024 Revision) \& IAEA/EIA reports.

# 2\. \*\*Python Processing:\*\* `scripts/clean.py` reads `data/raw.txt`, computes Mean, Growth Rates, and CAGR, and outputs `data/cleaned.json`.

# 3\. \*\*Frontend:\*\* Lightweight responsive dashboard using Tailwind CSS and Chart.js.

# 

# \## 🤖 AI Disclosure \& Prompts

# \- \*\*AI Tool Used:\*\* Claude / ChatGPT (Assisting Python boilerplate \& risk taxonomy scaffolding).

# \- \*\*Prompt Example:\*\*

# &#x20; > "Provide a structured JSON schema for UN population projection metrics from 2024 to 2100. Write a clean Python script to calculate CAGR and period-over-period growth without external heavy dependencies."

# \- \*\*Data Verification \& Anti-Hallucination:\*\*

# &#x20; - LLMs often mix UN 2022 projection (10.4B peak) with UN 2024 revision (10.18B peak). All demographic numbers were validated against the official UN WPP 2024 report.

# &#x20; - Geopolitical risk items strictly delineate verified operational facts (e.g., IAEA 60% enrichment) from forward-looking market inferences (e.g., crude premium).
